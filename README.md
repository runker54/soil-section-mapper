# 土壤断面制图工具 SoilSection Mapper

[简体中文](README.md) | [English](README.en.md)

土壤剖面断面图桌面制图软件：在影像底图 + DEM 晕渲 + 土壤类型图底图上绘制断面线与断面点，生成土壤类型断面图（地形剖面、土种色带、断面点表格、地带性界线、方向指针）。

技术栈：Rust · Tauri 2 · MapLibre GL · GDAL 3.10（动态加载 FFI），断面前端为矢量 SVG 渲染。

## 功能

### 地图工作台
- 底图：在线影像底图（WMTS 栅格瓦片，可在图层中隐藏）、DEM 高程晕渲、土壤类型图矢量着色
- 模式：浏览 / 画断面线（双击结束）/ 布点（吸附断面线）/ 识别（点击图斑查属性）/ 测距（球面距离）
- 图层面板：列表顶 = 地图顶层（QGIS 惯例）；拖动调序、勾选显隐、调色、样式（线宽·点大小）、缩放到图层、移除
- 多套自绘剖面并存；多套导入线/点图层并存；沿线等距布点；点位选中拖动；Ctrl+Z 撤销

### 断面生成与制图
- 数据源：自绘剖面 或 导入线/点文件（shp / gdb / geojson / gpkg），生成时弹层选择
- 断面计算：采样间距、两端外延、平滑、定向（左高右低/反向/按线）、垂直夸张（自动/手动）
- maximin 单元格宽度算法：相邻点中点分段 + 二分最小格宽，窄格文字可读、点位标注落入格内
- 显示行：勾选、拖动排序、行内独立行高；整体字号作用于全部文字；图幅宽度 0~6000 px；滑块与数字输入双通道
- 跨土种分段行（默认开启）：任意表格行相邻同值自动合并为一条宽格（土种编号/剖面构型同码合并、地貌类型跨土种分段），分段边界与土种格不对齐、可拖动微调，双击边界合并、双击段内拆分、点击段编辑文字；地貌类型/母岩母质优先显示断面点表格中的值（无值时按高程/土类推导）；点击图面空白取消选中
- 高程刻度轴与距离轴均可独立开关
- 地带性界线：名称含土类名自动取土类色
- 地形配色（默认土种色）：表层着色贴地形起伏——每土种段表面向下固定厚度取土种色，谷地低处同样有颜色，带下为全局一致的灰度渐变；备选经典灰渐变，渐变下两级颜色可调
- 断面点表格：全字段可编辑、按里程沿线提取土种/高程、拖动重排、增删行与图/地图同步

### 数据与导出
- 内置土种编号表（1329 条）与土种色带表（1505 条），支持用户 JSON 导入覆盖、模板导出、恢复内置
- 导出 PNG（1×~4× 分辨率）、分段明细 CSV；项目保存/打开
- CRS 自动识别；EPSG:4326/4490 自动转 CGCS2000 三度带参与计算；缺坐标系的文件装载时警告

## 底图服务说明

在线影像底图来自第三方网络地图服务，其版权与使用条款归服务提供方所有。本项目仅用于土壤调查制图的研究与学习，请勿将底图用于商业发布；正式项目使用请自行申请相应的地图服务许可并遵守其条款，软件界面中亦可随时隐藏该底图（图层 → 影像底图）。

## 环境要求

- Windows 10/11（64 位）、WebView2 运行时
- 开发构建需 Rust 工具链与 GDAL 运行时目录

## 目录结构

```
soil-section-studio/

│   ├── index.html / style.css
│   └── vendor/           maplibre-gl 本地依赖
├── src-tauri/
│   ├── src/
│   │   ├── commands.rs   Tauri 命令层（装载/计算/查询/表导入）
│   │   ├── pipeline.rs   断面计算管线
│   │   ├── gdal_ffi.rs   GDAL 动态加载 FFI
│   │   ├── builtin.rs    内置编码/色带表 + 用户覆盖
│   │   └── bin/fulltest.rs  后端自测（20 项）
│   ├── resources/        soil_codes.json / soil_colors.json
│   └── tauri.conf.json
├── test-fixtures/        fulltest 固定数据
└── CLAUDE.md             构建/测试/打包流程
```

## 构建与测试

```bash
# GDAL 运行时：含 gdal*.dll 的目录（伴生 gdal_data/ 与 proj_data/），
# 程序自动探测 exe 同级 gdal\ 目录，也可在界面手动指定
cd src-tauri
cargo build --release               # 前端随 frontendDist 编译期嵌入，改动前端后同样重跑
cargo run --release --bin fulltest  # 后端 20 项自测
```
